# 《糖块突围》AI 美术素材产出工具选型报告

> 依据：《糖块突围》美术风格描述（`Docs/糖块突围_美术风格描述词.md`）+ 开发策划案 v1.1（§10 美术规格、§11 音效规格、§12 MVP 范围）
> 调研时间：2026-10
> 结论口径：只回答"这个项目现在该用哪些工具"，不做工具大全。

## 0. 结论先行

**一句话**：《糖块突围》的美术难点不在"画得像"，而在"30 多个造型 + 40 多个图标长得像同一盒糖里拿出来的"。所以选型的第一标准是**风格能不能锁死**，第二标准才是出图好不好看。而模型本体（角色/敌人/武器的最终 3D 资产）和糖材质 shader 恰恰是 AI 最帮不上忙、也最不该交给 AI 的部分。

**三档推荐（按预算）**

| | 方案 | 月成本 | 覆盖 |
| --- | --- | --- | --- |
| **A · 零预算（推荐先从这里起步）** | **腾讯混元3D**（免费）+ **LiblibAI / 即梦**（国内生图）+ **ComfyUI + Krea 2 / Z-Image Turbo**（本地自训风格 LoRA）+ **UE5 手写描边材质** + 免费音效库 | ￥0 | 氛围图、参考图、图标草案、3D blockout、音效草样 |
| **B · 小预算（推荐主力）** | A + **Scenario.gg Pro $45/月**（自训风格 LoRA + 650 模型聚合 + 批量出图 + 3D 转档）+ **Recraft**（矢量图标，按量 $0.007–0.08/张）+ **ElevenLabs Starter $6/月**（音效，含商用授权） | ≈ $51–70 | 全流程：设定图 → 图标 → 音效；3D 仍手搓 |
| **C · 进阶** | B + **Meshy Pro $20/月**（3D 生成 + UE 官方插件）/ **Hyper3D Rodin $30/月**（四边网格）+ **Suno**（音乐）+ 云端 Midjourney（审美校准） | ≈ $100–120 | 全流程 + 可选 3D 辅助 |

**明确不采购的四类**（理由见 §3.6、§4.3）：
1. **AI 骨骼/动画工具** —— 策划案 §10.5 已定死"程序化形变 + 关键帧，不做骨骼关节动画"，整条产品线用不上。
2. **AI 场景/世界生成器**（HY-World 这类）—— 我们是 2m 方格 + 程序化拼装的三层地图，不需要。
3. **AI 糖材质 shader 生成** —— 不存在这种工具，§10.1 的"一套通用糖 shader（SSS + 结晶法线 + 上釉高光 + 内部气泡）"只能手写。
4. **高精度 3D 扫描/重建** —— 与造型语言冲突。

## 2. 风格给了选型三条硬约束

《糖块突围》的风格不是随便一种卡通，它对工具有三个很具体的要求：

1. **风格一致性 > 单张惊艳度。** 一个 demo 要 30+ 个造型、40+ 个图标，全部必须"看起来是同一盒糖里拿出来的"。所以**能不能锁风格**（参考图 / 风格模型 / 自训 LoRA）比"这个工具出图好不好看"重要得多。任何不能做风格锁定的工具，在这个项目里只能当一次性脑暴用。
2. **轮廓优先。** 策划案 §10.1 的红线是"半透明绝不能糊掉轮廓"，所有糖质物体必须有不透明描边 + 贴地实心投影。这意味着生图时必须能稳定产出**干净、可分离、边缘清晰**的主体；油画感强、笔触碎、背景融合的模型在这里是负分。
3. **55° 俯视 + 低细节。** 固定俯视角下很多东西只看得到顶面和侧面，且造型极简。所以：
   - 3D 生成工具的价值被大幅削弱——我们要的不是"高精度扫描感"，而是"圆角开 box"；
   - 生图 prompt 必须能表达"正交 / 俯视 / 几何 / 无细节"这类摄影与造型语言，纯艺术向模型反而不听话。

**本项目结论（重要）**：**不要把 3D 生成的产出当正式资产。** 理由是风格决定的——
- 我们要的是"8–12px 圆角 + 禁尖角"，这是**开 box + bevel 手调**出来的；AI 3D 输出的是三角面汤，圆角是"看起来圆"而不是可控的倒角半径，进 UE 后没法统一。
- 策划案要求"12 把武器共用 3–4 个材质球"，这依赖 UV 规范统一；AI 生成模型的 UV 展开各不相同，反而增加统一成本。
- 三个角色都是立方/四面体/胶囊，一个熟练的建模同学在 Blender 里 20 分钟能做出比 AI 更干净的版本。

所以 3D 生成的正确用法是：**出 blockout 找比例、出参考图给人看**（比如"腐果"这种"过分鲜艳的水果形大几何体"到底长什么样），正式资产手搓。

### 3.4 游戏专用平台与管线整合

**Scenario.gg** —— 目前最贴合本项目需求的单一平台，值得单独说：

- **能力**：自训风格 LoRA（**10–30 张**图训风格 / 5–15 张训角色，30 分钟–数小时完成）；Multi-LoRA 把"风格 + 角色"叠加；内置 **650+ 模型**聚合（含 Gemini 3.1、GPT Image 2、Seedream 5.0 Lite、FLUX 2 Pro、Kling、Seedance、Tripo P1、混元 3D 3.1 Pro、Meshy 6、ElevenLabs 3）；**Generative 3D** 支持导出带 PBR 的 GLB/OBJ/**FBX**；**Character Turnaround（6 角度）** 模板可直接产出给建模同学用的六视图；批量生成 + 可发布成"一键 app"的模板；**API + MCP server**。
- **价格**：免费档 → **Starter $15/月**（1500 credits，**不含自训**）→ **Pro $45/月**（解锁自训 + 优先队列 + 编辑模型）→ Max $75/月（25 人）。**积分不结转到下月**，这是主要成本陷阱。
- **对本项目的意义**：它一个订阅就覆盖了"风格 LoRA + 多模型对比 + 批量出图 + 六视图 + 3D 转档 + API"，等于把 §3.1/§3.2/§3.3 的碎片串起来了。**如果想省事，这是最值得花的一笔钱。**
- **注意**：$15 的 Starter **不能训模型**，而训风格正是我们最需要的功能，所以实际要按 $45 预算。

**Unreal 侧整合**：

- 项目**已经**有一套 UE MCP 桥（`ChiR24/Unreal_mcp` / McpAutomationBridge），AWKZZ-9 的隔离冒烟测试结论是**"部分可用"**——资产创建、编译、PIE、截图能跑通，但运行时 Widget 显示未能验证、PIE 画面全黑，**不建议把运行时 UI 与视觉验收交给它独立完成**。这条结论直接影响美术管线：**用 MCP 做批量资产导入/摆放可以，用它做"AI 自动验收美术效果"不行，仍需要人截图确认。**
- 描边方案（§10.1 红线的技术实现）：UE5 里主流是 **后处理材质 + Custom Depth/Stencil**（对"糖质物体"这一层描边）或**反向壳（Inverted Hull）**。透明物体（冰糖、汽水糖罐、玻璃管）用自定义深度要特别注意半透明不写深度的问题，建议对透明件用反向壳、对不透明件用后处理。**这部分没有任何 AI 工具能代劳，属于 Technical Artist 的手工活。**
- 场景模块拼装可以用 UE 自带的 **PCG 框架**做程序化摆放，比 AI 世界生成器靠谱。

### 3.6 动画：本项目明确不需要 AI 动画工具

策划案 §10.5 写得很清楚：**"squash & stretch：落地压 0.8、起跳拉 1.15；移动 ±3% 呼吸；受击倾 8° 0.15s 弹回。程序化形变 + 关键帧，不做骨骼关节动画。"**

这意味着 Cascadeur、Move AI、Plask、DeepMotion、Mixamo、Animate Anyone / NVIDIA Kimodo 这一整类工具**在本项目里没有用武之地**——我们连骨骼都不绑。这是本报告里最重要的一条"不买"结论，能省掉一整条产品线的调研与预算。

§10.5 要的效果应该在 UE 里用 **材质/顶点动画 + Timeline + Timeline 曲线驱动 Scale** 实现：落地压扁、起跳拉伸、受击倾斜都可以用 Actor 的 Scale 曲线加一个简单的弹簧回弹，**不需要任何 AI**，也不需要动画师。

### 3.7 视频（演示视频）

策划案 §12.3 验收清单最后一条是"录一段演示视频"。这是**录屏**，不是生成视频，用 OBS 即可。若要额外做一段宣传向的片头，可选用可灵 / 即梦 / Veo 系的视频生成，**但这不计入美术资产**，优先级放在最后。

## 4. 选型结论

### 4.1 最终推荐组合

**主力链路（预算 ≈ $51/月 + 按量）：**

| 环节 | 选用 | 成本 | 理由 |
| --- | --- | --- | --- |
| 风格锚定 + 批量设定图 | **Scenario.gg Pro**（自训糖块风格 LoRA + 650 模型 + 六视图模板 + 3D 转档） | $45/月 | 一个订阅解决"风格锁死 + 批量出图 + API/MCP" |
| UI / 图标 | **Recraft V4.1**（矢量直出） | 按量，矢量 $0.05–0.08/张 | 只有它能给可编辑 SVG，直接进 UMG |
| 音效 + 角色语音 | **ElevenLabs Starter** | $6/月 | 覆盖 §11 整张表，含商用授权 |
| 3D 模型本体 | **Blender + UE5 建模工具（手搓）** | ￥0 | 圆角几何手搓更快、更可控 |
| 糖材质 shader | **UE5 手写** | ￥0 | 无 AI 替代品 |
| 描边 / 投影 | **UE5 后处理 + Custom Stencil / 反向壳** | ￥0 | 同上 |
| 地图模块 | **UE5 PCG + 2m 方格手工模块库** | ￥0 | 策划案 §2.1 已定 |

**零预算替代链路：**

| 环节 | 选用 | 说明 |
| --- | --- | --- |
| 生图 + 风格 LoRA | **LiblibAI**（国内在线训 LoRA）或 **即梦**，或本地 **ComfyUI + Krea 2 / Z-Image Turbo**（Apache 2.0 可商用） | ComfyUI 路线需要一张显卡，但完全免费且控制力最强 |
| 3D blockout | **腾讯混元 3D**（免费、国内直连） | 只用来出草模和参考 |
| 图标 | **Recraft 免费档** / 人工矢量重描 | 或用开源模型出图后人工矢量化 |
| 音效 | 免费素材库（Freesound 等，注意逐条查授权）+ 人工处理 | 质量会明显下降，但零成本 |

### 4.2 为什么是这套，而不是"直接用 Midjourney 全搞定"

- **Midjourney 的问题是它不解决问题。** 它出单张图最好看，但本项目要的是"30 个造型 + 40 个图标互相同一个风格"，这需要**风格模型 + 批量管线 + 结构化输出（六视图 / SVG）**，而不是最强的单图模型。把它当"风格校准器"用（出 5–8 张基准图）是合适的，当主力生产线不合适。
- **Scenario 的价值在于"把一致性做成产品"。** 自训 LoRA + Multi-LoRA + Character Turnaround 模板，正好逐条命中 §2 的三条硬约束。
- **Recraft 的价值在于矢量。** 生图模型出的是位图，直接当 UI 用会在 UMG 里糊掉、也没法换色；SVG 直出是硬需求。
- **3D 和 shader 坚持手搓。** 这是本报告最想强调的一条：这个风格看起来"简单"，简单到 AI 生成的收益几乎为零，而返工成本很高。

### 4.3 不建议采购

| 类别 | 代表 | 不买的原因 |
| --- | --- | --- |
| AI 骨骼 / 动作捕捉 / 动画 | Cascadeur、Move AI、DeepMotion、Mixamo、Animate Anyone | §10.5 明确不做骨骼关节动画 |
| AI 3D 世界 / 场景生成 | Tencent HY-World 2.0、Alibaba Happy Oyster | 三层地图是 2m 方格程序化拼装，规模与需求都不匹配 |
| AI 材质生成 | StableMaterials、DreamMat | 糖 shader 必须手写，没有替代品 |
| 高精度 3D 扫描 / 重建 | Polycam、AnyRecon、Luma | 与"圆角几何"造型语言直接冲突 |
| 专业级 3D 生成订阅 | Rodin Business、Luma Pro | 精度远超过本项目需要，为不需要的精度付费 |

## 5. 落到本项目的执行方案

按策划案 §9.1 的优先级，美术侧建议这样用 AI：

**第 1 步（1–2 天）· 立风格基准**
用 Scenario / Midjourney 按 `Docs/糖块突围_美术风格描述词.md` 那段描述，产出 6–10 张"糖块突围基准图"（L1/L2/L3 各一张环境、方糖角色一张、硬糖手枪一张、糖条 HUD 一张）。**这一步的产出要人签字定稿**，之后它就是全项目的视觉标尺。

**第 2 步（1 天）· 训风格 LoRA**
拿第 1 步的基准图当训练集（10–30 张，可先用 AI 批量扩图凑够），训练一个"糖块风格"LoRA。

**第 3 步（3–5 天）· 批量出设定图**
用这个 LoRA 批量产出 §4.1 的 MVP 两把武器（硬糖手枪、糖块步枪）、§6 的 MVP 三种敌人（霉兽、糖渍体、偷核鼠）、以及方糖角色。**每张都由人改稿定稿**，改稿过程留档（课程与版权都需要）。

**第 4 步（2–3 天）· UI 图标**
糖条血条 / 糖粒弹夹的视觉规范在 UE 里手工搭（这是 shader + UMG 的活）；消耗品、属性载体、糖封罐的**图标**用 Recraft 出矢量，统一描边与稀有度配色。

**第 5 步（并行）· 音效**
用 ElevenLabs 按 §11 的表格逐条生成，重点做"玻璃管砸下""霉兽/糖渍体死亡""SSR 三音琶音"这三条最有辨识度的。

**第 6 步 · 手搓资产**
建模同学按定稿参考手搓方糖 + 2 武器 + 3 敌人；TA 手写糖 shader 与描边后处理。**这一步不用 AI。**

> **与 MCP 的关系**：UE MCP 桥（AWKZZ-9 验证"部分可用"）可以用来自动化**批量导入与摆放**，但**不要**让它承担美术效果的自动验收——它当前的 PIE 截图全黑、Widget 显示未经验证，视觉验收必须由人截图确认。

## 6. 合规与风险

### 6.1 课程侧（本项目最硬的约束）

策划案 §0 已经把口径写死了：**"AI 出氛围图/图标/代码辅助，造型定稿与验收由人负责"**。所以：

- AI 产出**只能**进"参考、草图、氛围、图标、音效"这几栏，**造型定稿（角色/敌人/武器的最终模型与材质）必须有人类的明确创作动作**；
- 建议保留"人改过"的证据链：AI 草图 → 人工改稿 → 定稿。这既是课程验收要求，也是 6.2 里版权主张的前提。

### 6.2 平台与版权

- **Steam（若将来上架）**：Valve 在 2026 年 1 月调整了 AI 披露政策——后台效率工具（写代码的 Copilot 之类）**不再需要披露**；但**玩家能直接看到/听到的预生成内容**（贴图、立绘、配音、文本）仍必须在商店页做 "Pre-generated" 披露，实时生成的内容则要额外加安全护栏与举报入口。开发者对所有已披露 AI 内容承担版权与合规的全部责任。
  - 对本项目的实际含义：本课程 demo 不上架则无此义务；一旦要上架，**AI 出的图标/贴图要如实勾选**。而在当前美国版权实践中，纯 AI 生成且无人改动的资产基本拿不到版权保护——这又是一个"必须有人工改稿"的理由。
- **商用授权**：各工具"免费版"和"付费版"的商用条款差别极大。选型时必须逐项确认三件事：① 我的订阅档位是否允许商用；② 输出物本身是否受限（部分模型限制的是"模型怎么用"而非"输出的图片怎么用"，例如 FLUX 系列明确允许商用生成的图片）；③ 是否需要署名。
  - **本项目踩坑提醒**：ElevenLabs 免费档**没有**商用授权且需署名；Qwen-Image **2.1 版是研究许可**（1.0 / 2512 / Edit 才是 Apache 2.0）；Civitai 上的 LoRA 有约 **43.6%** 不允许出售生成图，用之前要逐个看权限图标。
- **国内可及性**：Midjourney / ChatGPT / Gemini 系在国内访问与支付都不方便；国产链路（即梦、LiblibAI、腾讯混元 3D、Tripo3D、Qwen 系开源模型）在这个项目里是**现实选项而非备胎**。
- **价格时效**：AI 工具价格 2026 年仍在快速变动（3D 赛道半年内从 $60 降到 $20 甚至免费）。**本报告的价格是 2026-10 的快照，下单前请以官网为准。**

### 6.3 主要风险

| 风险 | 后果 | 对策 |
| --- | --- | --- |
| 风格漂移 | 30+ 个资产不像同一个游戏 | 必须做风格锁定（自训 LoRA + 固定参考图集 + 固定参数），不接受"每次重新描述一遍" |
| AI 模型拓扑不可用 | 3D 资产进 UE 后要重做，等于白干 | 3D 只用 AI 出 blockout / 参考；正式模型手搓，用开 box + bevel 做可控圆角 |
| 透明背景与描边做不出来 | 违反 §10.1 红线 | 生图统一用纯色/纯白底，描边与投影在 UE 材质里做，不指望生图直出 |
| 图标是位图不是矢量 | UI 放大糊、UMG 里无法改色 | UI 图标走 Recraft（矢量直出）或人工在矢量软件里重描 |
| 订阅积分不结转 | 月中断供 | Scenario 的 credits 不结转到下月，按需买最小档，别一次性买大包 |
| 工具订阅成本 | 学生团队预算 | 先用零预算链路（混元 3D + LiblibAI / ComfyUI + 免费素材）跑通验证，确认有效再付费 |
