## 1. 一句话玩法

玩家扮演糖做的小人，在三层垂直的发霉糖果果园里搜刮果核（金币）、打怪、逐层下探拿更好的货；**4:00 层间通道封死、巨大玻璃管从天上砸下来成为逃生门**，你必须在自己所在的那一层逃出去。死了果核全丢，除非带着「糖封罐」。

三条设计红线：
1. **十秒看懂战场**：固定俯视，靠形状+颜色+白闪判断敌我与稀有度。
2. **越深越肥也越险**：三层难度/奖励/复杂度递增，4:00 后路断，回不去。
3. **糖是造型，几何是骨架**：圆角几何+糖材质，半透明绝不能糊掉轮廓。

## 2. 三层地图与单局时间轴

### 2.1 三层结构

| 层 | 主题 | 环境 | 敌人强度 | 奖励 | 逃生门数量 |
| --- | --- | --- | --- | --- | --- |
| **L1 地面层** | 果园表层 | 开阔、简单、少量台阶 | 弱（T1 为主） | 基础物资、N/R 果核 | **4 个** |
| **L2 中层** | 分拣车间/冷库夹层 | 货架迷宫、高低差、传送带 | 中（T1+T2） | 更好的装备、SR 果核 | **2 个** |
| **L3 深层** | 腐心 | 复杂迷宫、多层高低差、视野差 | 强（T2+T3+精英） | 最丰厚、SSR 果核 | **1 个** |

- **层间连接**：楼梯/滑梯/垂直管道，0:00–4:00 三层互通，玩家自由下探。
- **4:00 逃离时间开始 → 层间通道全部封死（塌断/盖板落下），三层不再互通**。玩家当时在哪层，就只能用那层的逃生门。想拿 L3 的货就要接受"只有 1 个门可逃"的风险。
- 地图总尺寸约 100m×100m，每层独立布局；地块 2m 方格；波浪生成从玩家所在层开始。

### 2.2 时间轴

| 时间 | 事件 |
| --- | --- |
| 0:00 | 地块波浪铺开（约 7s）；身边 8m 内必刷 1 物资箱；三层互通开放 |
| 0:00–4:00 | 每 45s 全图掉 1 批物资（3–5 件）；每 60s 刷 1 批敌人；玩家逐层下探 |
| 2:30 | 第 1 次果核空投（光柱落点全图可见，落在 L1–L2） |
| **4:00** | **层间通道封死，三层隔离**；**巨大玻璃管从穹顶砸下**：L1×4、L2×2、L3×1，管口亮起旋涡；全图广播+精英刷新 |
| 4:00 | 霉潮从所在层边缘开始吞噬地块，每 20s 缩一环 |
| **4:30** | **开始空降敌人**：投放舱从天砸下（落点有提示圈），每 15s 一波，越接近 5:00 波次越密；同时第 2 次空投（SSR 果核）落下 |
| 5:00 | 未进入玻璃管 = 失败；全图腐坏 |

**胜负：**
- 走入玻璃管 → 成功，果核+背包物品入库结算。
- 死亡/超时 → **所有果核全部丢失**；若本局携带有「糖封罐」，自动保留最后拾取的 3 枚果核（见 §5.4）。

## 4. 武器系统

**1 个武器槽**（带背包道具→2 个）；徒手「糖拳」永久保底（伤害 5，攻速 2/s）。武器 N/R/SR/SSR 稀有度，靠材质区分。

掉落权重 N45%/R33%/SR17%/SSR5%；交售价 N20/R60/SR150/SSR400。

### 4.2 武器掷出与捡回规则（重要）

- 长按 G 扔出当前武器，耗体力 20；糖拳/副手不可扔。伤害=武器 DPS×2.0×稀有度系数(N1.0/R1.25/SR1.6/SSR2.0)×(1+3%/m，上限+30%)。
- **落地成"遗落物"，可捡回，但不刷新**：
  - 糖度保持掷出时的值（已霉变/受损的枪捡回来**不会恢复**）；
  - **弹夹保持掷出时的剩余子弹数**，不补满；
  - **上釉糖环可以捡起并再次掷出**（它本就是投掷武器，捡回后弹药/糖度状态不变）。
- 扔出后武器槽空，只剩糖拳；未捡回就撤离 → 武器丢失；阵亡 → 丢失。

### 4.3 糖度（【完整版】）

SR/SSR 武器 100 糖度：进霉潮或被孢子命中每秒 -1，归零本局伤害 -60%、不可掷械。**糖度只降不升**（见 4.2，捡回不恢复）。N/R 不受影响。

### 5.1 槽位

| 槽位 | 数量 | 说明 |
| --- | --- | --- |
| 武器槽 | 1（背包道具→2） | §4 |
| 副手槽 | 1，不可扩 | 剥糖刀/汽水糖罐二选一，F 触发 |

- **副手·汽水糖罐**：F 后移速+45%、近地悬浮 6s，可越 1m、免疫减速面；结束后充能 25s。
- **随时丢弃**：道具栏里**任何物品（消耗品、属性载体、糖封罐）都可以随时主动丢到地上**，成为可拾取物；不想要的 Build 现场换掉。

### 5.4 其他道具

- **名称**：糖封罐
- **造型**：一个蜡封口的玻璃小罐，罐内泡着一枚发光果核。
- **获取**：局外商贩处花果糖购买带入局，或局内稀有拾取。
- **效果**：本局死亡/超时失败时，**自动保留最后拾取的 3 枚果核**（其余果核与装备仍丢失）。
- **消耗**：触发一次后消失；局内未触发则不消耗。
- 这是失败惩罚的唯一安全阀，不做其他兜底。

## 7. 数值公式（程序照抄）

```
最终伤害 = 基础伤害 × (1+攻击%) × (1−目标减伤%) × 属性系数
         × 距离衰减 × 暴击倍率 × 部位系数 × 糖度系数(正常1.0/糖渣0.4)
目标减伤% = 护甲 / (护甲 + 120)
距离衰减 = clamp(1 − 0.04×max(0, 距离−射程), 0.5, 1.0)   // 冰糖狙击豁免
基础暴击 5%/×1.5；冰糖狙击 25%/×2.0；糖丝鞭背刺×2.0
```

**经济：** 果核 N60%值15 / R28%值45 / SR10%值130 / SSR2%值400（期望约 42.6/枚）。单局捡 8–10 枚。货币只有**果糖**（撤离后交售果核获得，局外买东西用）。

## 8. 局外：商贩摊点

1. **角色解锁**（唯一的长线成长）：

   | 商品 | 说明 |
   | --- | --- |
   | 武器 | 已解锁蓝图的武器，买了带进局（开局装备） |
   | 消耗品 | 回血糖/弹药糖/体力糖，花果糖批量买 |

- 存档只存：货币果糖、已解锁角色、已购武器蓝图、皮肤、累计果核数、最佳成绩。

## 10. 美术规格

### 10.1 风格
- 圆角几何（8–12px 圆角，禁尖角）+ 糖材质；一套通用糖 shader（SSS+结晶法线+上釉高光+内部气泡），12 把武器共用 3–4 个材质球。
- 稀有度靠材质：N 哑光硬糖 / R 有色结晶糖 / SR 透明冰糖 / SSR 上釉糖壳；掉落加贴地微光（N 无/R 淡黄/SR 淡蓝/SSR 金脉动）。
- 所有糖质物体必须有不透明描边（主色加深 2px）+ 地面实心投影，半透明不许糊轮廓。M0 实测光照。

### 10.2 镜头与 UI
- 俯角 55° 固定不旋转；遮挡物 40% 透明剪影 + 角色高亮描边。
- **血条改为「糖条」**：左上不是数字血条，而是一串排列的糖粒/糖柱段，按最大 HP 分段（如方糖 130 = 5 段），受伤从末端逐段熄灭；<30% 时糖条泛红。体力条同理用浅色小糖块。
- 中下：武器槽(1–2) | 副手槽(1，环形充能) | 道具槽×3；弹夹用糖粒点阵。右上装备图标；左下小地图（标三层、逃生门光柱、霉潮边界高亮）；中下偏上倒计时+"4:00 封层/霉潮推进"脉冲警告。

### 10.3 逃生门——玻璃管
- 4:00 一根巨大透明玻璃管从穹顶垂直砸下插在地面，直径约 3m、高 8m，管壁有糖霜结晶，管口内部发光旋涡。
- 砸下时镜头微震、地面裂纹；未到 4:00 时地图上只有淡影。L1×4/L2×2/L3×1 按层分布。

### 10.4 特效规则（修正）
- 命中：白闪 0.08s + 小糖粒溅射。
- 碎裂分材质：硬质糖（硬糖/冰糖/上釉）被打碎后碎块直接散落在地面停住，不弹跳；只有软质糖（棉花糖/软糖/汽泡糖）才做弹跳。
- 开箱：箱盖弹开+物品发光磁吸飞向 UI 槽位（贝塞尔 0.3s）。
- 玻璃管：落下嗡鸣+砸地尘土+旋涡持续流光。
- 空降敌人：投放舱砸地前 1s 地面红圈提示，砸下后舱盖炸开出怪。
- 霉潮：地块变暗+绒毛霉斑+边缘孢子雾，被吞地块下沉消失。
- 属性：寒=冰晶结霜 / 燃=火苗 / 裂=子弹分裂。
- 撤离成功：从角色处向外扩散白光，物资逐件飞入仓库。

### 10.5 动画
- squash & stretch：落地压 0.8、起跳拉 1.15；移动±3% 呼吸；受击倾 8° 0.15s 弹回。
- 程序化形变+关键帧，不做骨骼关节动画。
