# 《糖块突围》美术风格描述

《糖块突围》的美术是一盒摆在桌上的糖果战术沙盘：一切都用圆角几何搭成——立方、四面体、胶囊、球，没有尖角，也没有骨骼关节，靠整体的软糯形变来表演，形状本身就是角色的身份。表面统一是糖的材质，从哑光硬糖、半透明冰糖到油亮上釉分级，但再透也不许糊掉轮廓：每个糖质物体都锁着一圈不透明深色描边和一块贴地实心投影，保证固定 55° 俯视下十秒就能分清敌我和稀有度。颜色干净克制，随着下探变冷变脏——地面层是奶白、淡黄、蜜橙的甜腻果园，中层是薄荷绿与钢灰的分拣车间，深层沉进紫红、霉绿的腐心；稀有度只用一套固定色：N 哑光白、R 淡黄、SR 淡蓝、SSR 金。UI 也长在糖里：血条是一串会逐段熄灭的糖粒，弹夹是糖粒点阵，撤离点是一根从穹顶砸下的巨大玻璃管，管口亮着旋涡。整体情绪是"甜而紧张"——明亮的糖壳下面，压着倒计时、霉潮和随时会塌的路。
