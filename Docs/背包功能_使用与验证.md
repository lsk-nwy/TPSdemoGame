# 背包功能：使用与验证

## 这次实现了什么

- 战斗内 6×6 背包，共 36 格；一件物品占一格，不堆叠。
- 开局在玩家前方放置 5 件测试物品，靠近后按 `E` 拾取。
- 按 `B` 打开背包；打开期间暂停，鼠标可用于选择格子。
- 点击格子后可以“使用”或“丢弃”；按 `ESC`（也可以再按 `B`）关闭背包。
- 丢弃会在角色前方地面生成可再次拾取的物品，并短暂禁止立即捡回。
- 背包和物品不跨关卡保存；角色随战斗地图重建。

## 操作

| 操作 | 按键 / 位置 |
| --- | --- |
| 打开背包 | 战斗中按 `B` |
| 关闭背包 | `ESC`、再按 `B`，或点击“关闭 (ESC)” |
| 选择格子 | 鼠标点击 6×6 网格中的任意格子 |
| 使用物品 | 选中后点击“使用” |
| 丢弃物品 | 选中后点击“丢弃” |
| 拾取地面物品 | 靠近后按 `E`（沿用原有交互键） |
| 切换枪械元素 | 战斗中按 `Q`（火/水/冰循环，与背包互不影响） |

打开背包会暂停战斗，并停止开火、搜索和移动输入。`B` 键由角色的原生输入组件绑定；
`ESC` 关闭由背包 UMG 的 `NativeOnPreviewKeyDown` 处理，因此不会与战斗暂停菜单的 `Tab/ESC`
冲突。关闭后恢复战斗输入、隐藏鼠标并重新锁定视口。

## 测试物品

| Id | 名称 | 效果 | 用途 |
| --- | --- | --- | --- |
| `MintCandy` | 薄荷糖 | 恢复 25 生命 | 验证治疗与“生命已满”失败 |
| `EnergyDrink` | 能量饮料 | 8 秒移动速度 +40% | 验证限时增益与恢复 |
| `GoldTicket` | 金券 | 获得 30 金币 | 验证写入 PlayerState |
| `EmergencyKit` | 急救糖盒 | 恢复 60 生命 | 验证大额治疗 |
| `CaramelChunk` | 焦糖块 | 无法使用 | 验证材料、丢弃与重新拾取 |

物品定义在
`Source/TPSdemo/CandyFight/Inventory/CandyFightItem.h/.cpp` 的原生目录中。
每件物品有独立颜色；地面掉落物用不同颜色的球体区分，并在上方显示名称和交互键。

## 从哪里开始读

| 文件 | 职责 |
| --- | --- |
| `Source/TPSdemo/CandyFight/Inventory/CandyFightItem.h/.cpp` | 物品定义、原生测试目录、效果说明 |
| `Source/TPSdemo/CandyFight/Inventory/CandyFightInventoryComponent.h/.cpp` | 36 格格子、增删、使用、丢弃、拾取焦点、暂停与输入模式 |
| `Source/TPSdemo/CandyFight/Inventory/CandyFightItemPickup.h/.cpp` | 地面物品、旋转/浮动、提示组件、延迟可拾取 |
| `Source/TPSdemo/CandyFight/UI/CandyFightInventoryWidget.h/.cpp` | 原生 C++ UMG 6×6 布局、格子按钮、详情与操作按钮 |
| `Source/TPSdemo/CandyFight/UI/CandyFightItemPickupWidget.h/.cpp` | 地面物品上方提示 |
| `Source/TPSdemo/CandyFight/CandyFightGameMode.cpp` | 开局在玩家附近生成测试物品 |
| `Source/TPSdemo/CandyFight/CandyFightCharacter.cpp` | 创建背包组件、绑定 `B`/`E`、清理界面 |
| `Source/TPSdemo/CandyFight/Tests/CandyFightInventoryTests.cpp` | 目录、格子、使用、丢弃、拾取和 UMG 自动化测试 |

关键点：

- `FCandyFightInventorySlot` 只保存 `ItemId` 和 `Count`，物品资源不复制。
- `AddItem` 永远找第一个空格；相同物品不会合并，符合“一个物品占一个格子”。
- `UseAt` 先确认效果成功，再清空格子；满血治疗失败时物品保留。
- `DropAt` 先成功生成掉落物，再清空格子；生成失败时物品保留。
- 背包组件只负责数据和输入，界面只读取组件状态并转交按钮操作。
- 暂停由背包组件自己负责，关闭时如果流程已经切到结算/暂停界面，则不再强行解除暂停。

## 快速验证

### 编辑器内

1. 打开 `L_CandyFight_Frontend`，点击运行，从主菜单进入备战，再点击“进入战斗”。
2. 进入战斗地图后，等待屏幕出现“测试道具”提示；玩家前方有 5 个彩色球体。
3. 走到一个物品旁，按 `E`，屏幕左下会显示拾取信息和背包占用格数。
4. 按 `B`，确认打开 6×6 面板并暂停；点击带物品的格子，点击“使用”。
   - 薄荷糖/急救糖盒应回血；满血时使用会失败且物品保留。
   - 能量饮料使用后移动速度提高，约 8 秒后恢复。
   - 金券使用后 HUD 金币增加 30。
   - 焦糖块“使用”会提示无法使用。
5. 选中另一件物品，点击“丢弃”，关闭背包，走到前方用 `E` 重新捡起。
6. 按 `ESC` 关闭背包；再按 `ESC`，应打开原有的战斗暂停菜单。
7. 把 36 格填满后靠近物品按 `E`，应提示背包已满且物品仍留在地上。

控制台测试命令（角色被控制时）：

```text
InventoryTestAdd MintCandy
InventoryTestAdd EnergyDrink
InventoryTestSpawn GoldTicket
```

### 自动化测试

在“工具 / 测试 / 自动化”中运行以下测试：

- `CandyFight.Inventory.Catalog`


## 本次未做

- 背包不持久化，不接入仓库、商店或结算入库。
- 不支持拖拽、排序、堆叠和快捷键栏。
- 物品目录是原生 C++ 演示数据，不是 DataTable/DataAsset 产出流程。
- 测试物品只在战斗 GameMode 开局生成；正式关卡内容可用
  `ACandyFightItemPickup` 手动摆放或在蓝图里关闭 `bSpawnTestPickups`。
